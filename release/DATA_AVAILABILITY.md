# Data availability

The underlying images must be obtained from the original dataset provider, subject to licensing and ethical restrictions. Raw images, patient-level identifiers, patient-level predictions, and patient-level split CSVs are excluded from this public archive. Aggregate CSV tables and figures are supplied.

The original GitHub repository previously contained a patient-level split CSV with source identifiers and Colab paths. That file has been removed from the current GitHub branch, but earlier commits may retain it. Historical exposure should be reviewed separately.

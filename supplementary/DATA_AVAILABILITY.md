# Data availability and privacy

The underlying breast thermography images should be obtained directly from the original dataset distributor subject to its terms. Raw images and trained model checkpoints are not included in this GitHub repository.

**Existing public-file review needed:** The root-level `dataset_with_patient_split.csv` is already present in this public repository. It may expose source patient identifiers and machine-specific local paths. The authors should verify that redistribution is permitted and remove or replace the file if necessary. This update does not alter that existing file.

Only aggregate result tables and figures should be shared as the default. Per-patient prediction records, identifiers, raw data and personal file paths require a separate privacy and license assessment.
